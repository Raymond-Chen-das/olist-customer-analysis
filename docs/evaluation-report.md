# 評估與壓力測試報告（階段四）

交付模型：LogReg(class_weight='balanced')，特徵見 experiment-tracking。
建模集 66,717，正樣本率 2.96%。基準（seed=42）：ROC 0.611 / lift 1.82×。

## 1. 種子穩定度（5 個切分種子）
- ROC-AUC = **0.592 ± 0.008**；top-decile lift = **1.71 ± 0.20**。
- 誠實註記：std 小（效能穩定），**穩健估計約 ROC 0.59**；先前 seed=42 的 0.611 屬略偏樂觀的單一切分，應以 ~0.59 為準。

## 2. 時間泛化（早 75% 訓練 → 晚 25% 測試）
- ROC-AUC = **0.574**，top-decile lift = **1.63**（測試期正樣本率 2.76%）。
- 結論：時間外推下效能略降，無明顯時間漂移失效。

## 3. 移除首單品類特徵
- ROC-AUC = **0.563**（vs 含品類 0.611，退化 0.047）。
- 結論：品類是模型主要訊號來源，移除後退回接近隨機 → 印證 EDA 與驅動因子分析。

## 4. 可重現性
- Python 3.13.3；套件版本見 requirements.lock.txt。
- 所有隨機種子固定（split / KMeans / 模型 = 42）。
- 資料由 raw CSV 確定性重建（00→07 腳本依序可跑）。

## 5. 標籤觀察性註記（獨立程式碼審查發現）
- 複購標籤以「第二筆 *delivered* 訂單」偵測，但 cutoff 以「購買日」計算。少數在 180 天窗末尾下單、但快照時點尚未送達的複購，會被計為負樣本（censoring）。
- 方向為**保守偏誤**：正樣本率略為低估、模型任務更難而非更易 → 報告指標未被高估。
- 另：midnight 快照 + date() 截斷，使 cutoff 邊界約 1 天觀察性不完整（影響極微）。

## 總結
模型弱但**穩健且誠實**：種子穩定、時間可外推、訊號可歸因於品類。結論的適用邊界：僅憑首單交易資料，複購預測上限約 ROC 0.6；更高精度需行為/行銷資料。
